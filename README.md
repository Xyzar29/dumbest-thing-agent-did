`main.ts` writes a single line — at most 200 characters — about the dumbest thing my agent did today, to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), and enforces the gate itself (1–200 characters, one non-blank line).

> My agent spent an hour polishing my one-line entry, then deleted the punchline to save characters.
